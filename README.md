# SpawnPlugin 26.3
# A simple Bukkit/Paper spawn plugin.
#
# Commands:
#   /setspawn - Save the current location as the spawn point.
#   /spawn    - Teleport to the saved spawn point.
#
# Feature:
#   Players are automatically sent back to spawn if they fall into the void.
#
# Build with Gradle:
#   gradle clean build
#
# Then place the generated JAR from build/libs/ into your Paper/Spigot plugins folder.
#
# Start the server and use /setspawn once.
